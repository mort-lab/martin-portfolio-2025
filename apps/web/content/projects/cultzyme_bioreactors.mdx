As Frontend Developer at Cultzyme, I led the complete user interface redesign for their custom bio-reactor platform. The project involved transforming a legacy application into a modern experience with React, real-time API integration and development of a complementary desktop application.

## Key Features

- **Modern Interface**: Complete UI/UX redesign following modern design system principles.
- **Real-time Monitoring**: Dashboard with live bio-reactor data visualization.
- **Training System**: Platform for configuring and monitoring automated experiments.
- **Integrated LLM Chatbot**: Intelligent assistant for technical support and guidance.
- **Desktop App**: Electron application for offline monitoring and push notifications.

## Technology Stack

- **Frontend**: **React** with **TypeScript** for type-safe and scalable development.
- **Real-time**: **WebSockets** and **Pusher** for live data updates.
- **Desktop App**: **Electron** for cross-platform native application.
- **APIs**: Integration with **internal REST APIs** of the bio-reactor system.
- **Data Visualization**: Specialized libraries for scientific charts and metrics.
- **State Management**: Modern solutions for complex state handling.

## Technical Implementation

### Frontend Architecture

- **Component-based architecture** with functional React and custom hooks.
- **Complete TypeScript integration** for type safety in complex scientific APIs.
- **Custom hooks** for bio-reactor specific business logic abstraction.
- **Error boundaries** and robust handling for critical experiment data.

### Real-time Data System

- **WebSockets connection** for live sensor data streaming.
- **Pusher integration** for cross-device notifications and collaboration.
- **Data buffering** and optimization for large telemetry volumes.
- **Offline functionality** with automatic synchronization when connection returns.

### Scientific Data Visualization

- **Specialized charts** for bio-reactor data representation.
- **Time-series visualization** with zoom, pan and trend analysis.
- **Visual alerts** for critical experiment conditions.
- **Export functionality** for scientific data in standard formats.

### Complementary Desktop Application

- **Electron app** for monitoring when browser is not available.
- **Native notifications** for critical experiment alerts.
- **Offline data caching** for access to historical information.
- **Auto-updater** for secure distribution of new versions.

## How It Works

1. **Main Dashboard**: Unified view of all active bio-reactors and their metrics.
2. **Experiment Configuration**: Intuitive interface for complex parameter setup.
3. **Live Monitoring**: Real-time visualization of temperature, pH, oxygen and other indicators.
4. **Alert System**: Automatic notifications for out-of-range conditions.
5. **Post-Experiment Analysis**: Tools for data analysis and report generation.
